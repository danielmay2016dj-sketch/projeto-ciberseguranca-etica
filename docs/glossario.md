# Glossário

- **Autenticação:** processo de verificar a identidade de uma pessoa ou serviço.
- **Autorização:** permissão concedida para executar uma atividade dentro de limites definidos.
- **Credential stuffing:** tentativa de reutilizar credenciais expostas de um serviço em outro.
- **Hash de senha:** representação unidirecional calculada com uma função adequada para proteger senhas armazenadas.
- **Integridade:** propriedade de manter informação correta e detectar alterações indevidas.
- **MFA (autenticação multifator):** uso de mais de um fator de verificação para confirmar uma identidade.
- **Metasploitable 2:** máquina virtual intencionalmente vulnerável usada em treinamentos controlados; deve permanecer isolada.
- **Nmap:** ferramenta de mapeamento e auditoria de redes que deve ser usada apenas em escopos autorizados.
- **Password spraying:** tentativa de uma ou poucas senhas comuns contra várias contas.
- **Phishing:** tentativa de enganar alguém para obter informação ou induzir uma ação, geralmente por mensagens ou páginas falsas.
- **Snapshot:** ponto de restauração de uma máquina virtual.
- **Wordlist:** coleção de palavras usada em alguns testes; seu uso deve ser restrito a laboratório autorizado.
