# Capturas de tela (opcional)

Esta pasta pode guardar capturas reais da execução da simulação offline ou de uma prática futura em laboratório autorizado. A captura já existente mostra apenas a simulação didática local; não é evidência de execução de Nmap, Medusa ou DVWA.

Antes de adicionar qualquer imagem, confira que ela não mostra senhas, tokens, nomes completos, e-mails, endereços IP públicos ou outros dados pessoais. Não inclua capturas de tentativas contra contas ou sistemas reais.
