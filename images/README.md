# Capturas de tela (opcional)

Esta pasta está reservada para capturas reais feitas pelo estudante durante a execução local do quiz ou da simulação offline. Não há imagens de demonstração porque não foram fornecidas capturas reais.

Antes de adicionar uma imagem, confira que ela não mostra senhas, tokens, nomes completos, e-mails, endereços IP públicos ou dados pessoais. Não inclua capturas de tentativas contra contas ou sistemas reais. Use nomes simples, por exemplo `quiz-executado.png`.
